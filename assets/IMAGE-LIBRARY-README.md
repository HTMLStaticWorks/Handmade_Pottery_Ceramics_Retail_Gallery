# KADAVA — 40 Image Reference Library

Files:
- `images.csv` — 40 real, related image references with direct image URL, source page, category, suggested KADAVA placement, alt text and rights note.
- `images.html` — visual gallery of the same 40 references with filtering and source links.

The image references were researched from live pottery/ceramics sites and editorial pages. They are intended as a curated visual/reference library. Before production use, verify copyright, licensing and permission for each image. Prefer KADAVA-owned or properly licensed photography for the final website.

No dashboard, login or signup assets are included.
