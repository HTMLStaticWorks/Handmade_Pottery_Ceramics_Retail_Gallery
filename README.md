# KADAVA — Handmade Pottery & Ceramics

KADAVA is a responsive artisan pottery studio / gallery / shop website.

This version intentionally uses a cohesive image direction:
- warm natural daylight
- earthy clay and neutral surfaces
- pottery in lived-in contexts
- studio-making imagery
- close, tactile ceramic compositions

The image references were selected during web research from pottery/ceramics sources including Slow Pottery, Auroville Online Store, The Bengal Store, Amalfiee Ceramics and The India Shop. For a production client site, replace these with KADAVA-owned/licensed photography so the visual identity and usage rights are fully controlled.

Files:
- index.html
- style.css
- script.js

No dashboard, login or signup pages are included.

Features:
- Shop
- Collections
- Studio
- Artspace
- Commissions
- Contact / Connect
- Newsletter
- Social icons
- Footer information links
- Copyright
- Back-to-top control after scrolling
- Responsive navigation
- Scroll reveal animations
- Cart counter demo
- Commission enquiry modal
